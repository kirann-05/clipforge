Privacy policy

Last updated 9 November 2026.

Who this covers

ClipForge is a personal tool used only by its owner, on the owner's own computer, with the owner's own Google account.

Google data it uses

  • Google Drive: reads a video file the owner points it at, creates a ClipForge folder, saves finished clips there and deletes them after they are posted. It cannot see files it did not create, apart from a file the owner chooses to import.
  • YouTube: uploads finished clips to the owner's channel and reads basic channel details to confirm the right channel is connected.

Where data goes

Sign-in tokens and all video work stay on the owner's computer. ClipForge has no server, does not sell or share data, and does not use Google data for advertising or to train models. Google API data is used only to provide the features above, in line with the Google API Services User Data Policy, including its Limited Use requirements.

Removing access

Access can be removed at any time at myaccount.google.com/permissions.
